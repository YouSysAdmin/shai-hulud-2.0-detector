# shai-hulud-2.0-detector

```
Usage of ../shai-hulud-detector-darwin-arm64:
  -dir string
        Directory to scan (default ".")
  -fail-on-any
        Exit non-zero if any issues are found
  -fail-on-critical
        Exit non-zero if any critical issues are found
  -fail-on-high
        Exit non-zero if any high/critical issues are found
  -format string
        Output format: text|json|sarif (default "text")
  -sarif-out string
        Path to write SARIF report (for format=sarif) (default "shai-hulud-results.sarif")
```
